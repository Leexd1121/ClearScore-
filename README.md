# 净谱 · ClearScore

一个面向扫描曲谱的本地水印清理工具。它可以自动识别白色页面中的浅灰背景和半透明水印，在尽量保护音符、谱线、数字及文字的前提下，输出更干净的 PDF、图片或 Word DOCX。

ClearScore 提供完整的桌面图形界面，不需要命令行、账号、API 或云端服务。文件只在本机处理，适合吉他谱、五线谱、六线谱以及其他以深色内容为主、浅灰水印为背景的文档。

## 项目特点

- **自动识别浅灰水印**：分析页面的亮度和颜色分布，自动选择合适的清理阈值。
- **保护曲谱内容**：阈值以下的深色像素保持原值，并额外检测、保护长水平谱线。
- **处理前后可视化对比**：提供原始文件、清理结果、左右对比和改动区域四种视图。
- **支持手动微调**：自动结果不理想时，可关闭自动模式并调整去除程度。
- **支持多种文档格式**：可处理 PDF、常见图片、多页或多帧图片，以及包含嵌入图片的 Word DOCX。
- **尽量保留原始结构**：PDF 仅替换受支持的嵌入图片；DOCX 仅替换文档中的图片，正文、样式、表格和版式数据保持不变。
- **完全本地运行**：没有登录、遥测、API 密钥、云端识别或自动上传。
- **四种界面语言**：支持简体中文、English、Русский 和 ئۇيغۇرچە；维吾尔语界面采用从右到左布局，曲谱画面不会镜像。
- **面向普通用户的桌面应用**：Windows 便携版解压即可使用，不弹出命令窗口。

## 支持格式

| 输入格式 | 默认输出 | 说明 |
| --- | --- | --- |
| PDF | PDF | 处理扫描页中的大型 RGB 或灰度图片，保留页面尺寸、裁剪、旋转和绘制指令 |
| JPG、JPEG、JFIF、PNG、BMP、DIB、WebP | PNG | 也可保存为 TIFF、无损 WebP、PDF 或 JPEG |
| TIFF、GIF、APNG、动态 WebP | TIFF 或 PDF | 处理全部页面或帧；导出为静态页面，不保留动画时序 |
| HEIC、HEIF、AVIF、JPEG 2000、ICO、TGA、PNM 等 | PNG | 解码后清理；当前不导出 HEIC |
| Word DOCX | DOCX | 只替换受支持的嵌入图片，保留可编辑文档结构 |
| 旧版 Word DOC | — | 需先在 Word 中另存为 DOCX |

透明图片会保留 alpha 通道。EXIF 方向会在处理前归正。JPEG 输出会再次进行有损压缩，因此软件会在保存前给出提示。

Word 预览显示的是文档中的嵌入图片，并不是完整的 Word 页面渲染。浮动文字水印、矢量图形、外链图片和旧版 DOC 文件不在自动处理范围内。

## 使用方法

### Windows 便携版

1. 从 GitHub Releases 下载 `ClearScore-1.1.0-windows-x64.zip`。
2. 解压完整压缩包，不要单独移动可执行文件。
3. 双击 `ClearScore/净谱.exe`，并保留同目录下的 `_internal` 文件夹。
4. 点击“打开文件”，或直接将文件拖入窗口。
5. 在原始、清理、左右对比和改动区域之间切换，放大检查音符、数字与浅色符号。
6. 如有需要，关闭自动识别并调整去除程度。
7. 点击“保存清理结果”，另存为新文件。

预览区域支持滚轮滚动、`Ctrl + 滚轮` 缩放和鼠标拖动平移，也可以一键适应页面或页面宽度。

## 工作原理

ClearScore 使用确定性的图像规则，而不是生成式 AI 或 OCR。程序会寻找白色页面中显著的浅灰背景峰值，根据亮度、色差和谱线形态决定哪些像素可以清理：

1. 分析图像直方图并寻找可能的浅灰背景。
2. 保护较深的黑色或灰色内容以及有明显颜色的像素。
3. 检测连续的水平谱线，减少浅色线段被清除的风险。
4. 将符合水印特征的背景像素变为白色。
5. 生成处理统计和可视化差异，供使用者复核。

该过程可重复、可检查，不会重新绘制或猜测乐谱内容。

## 适用场景与限制

ClearScore 最适合以下文件：

- 白色或接近白色的页面；
- 黑色或深色的音符、谱线和文字；
- 浅灰、低饱和度、面积较大的背景水印；
- 以整页扫描图片构成的 PDF。

如果水印和乐谱已经合并到同一张位图中，任何软件都无法仅凭最终图片精确恢复被覆盖前的全部像素。ClearScore 会保护可判断的深色内容，但位于清理阈值以上的浅色符号仍可能受到影响。导出前请使用对比视图放大复核。

以下内容可能被跳过或无法可靠分离：

- 纯矢量 PDF、独立矢量水印或内联小图片；
- 与音符颜色接近的深色水印；
- 摄影背景、大面积彩色背景或合法的浅灰插画；
- PDF 中的 CMYK 图片或复杂透明蒙版；
- 带密码、表单或数字签名的 PDF；
- Word 中的文字水印、形状和矢量图形。

单次处理上限为 300 MB、300 页或帧；单张及累计解码图像上限为 6000 万像素。当前发布的便携版面向 Windows x64，其他系统可从源码运行。

## 多语言界面

语言可以在软件右上角即时切换，并在下次启动时恢复。翻译覆盖操作按钮、状态、错误、帮助和保存提示。维吾尔语界面采用 RTL 布局，同时保持曲谱、数字和文件名的正确方向。

项目中的多语言文案按实际功能场景编写，并通过界面切换、占位符、字符覆盖和布局测试。详细说明见[本地化文档](docs/LOCALIZATION.md)。现有检查不等同于母语编辑认证，欢迎母语使用者提交改进建议。

## 从源码运行

需要 Python 3.12 或更高版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
.\.venv\Scripts\python run.py
```

依赖版本记录在 `requirements.txt` 中。安装依赖需要联网，软件运行及文件处理不需要网络。

## 项目结构

```text
clearscore/
├── app.py              # PySide6 桌面界面

docs/                   # 本地化、隐私、验证和发布文档
.github/workflows/      # GitHub Actions 自动测试与构建
```

## 隐私与安全

ClearScore 不会主动上传用户文件。语言偏好只保存在本机，应用不需要 API 密钥。

为了保留原始文档结构，导出的 PDF 或 DOCX 可能继续包含原文档已有的作者等元数据；手动保存的 JSON 处理报告也会包含输入文件名和文件摘要。公开这些文件前请自行检查。

源码发布采用明确的公开文件清单，并在打包时检查常见凭据、本机身份标记、绝对用户路径和演示素材摘要。私人曲谱、处理结果、Git 历史、本机配置、缓存和日志均不进入公开包。详细范围见[隐私说明](docs/PRIVACY.md)。
