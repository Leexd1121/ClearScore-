# 净谱 ClearScore v1.1.0

新增图片、Word DOCX 和四语界面。

- 支持 JPG、PNG、BMP、WebP、TIFF、GIF、HEIC、AVIF、JPEG 2000 等图片。
- 多页和多帧完整导出为 TIFF 或 PDF；透明度、像素尺寸和 EXIF 显示方向受保护。
- 默认无损 PNG；可选 TIFF、无损 WebP、PDF，JPEG 输出会提示有损压缩。
- Word DOCX 仅替换嵌入图片，保留文字、表格、样式及版式数据；预览明确标注为嵌入图片。
- 中文、英文、俄语、维吾尔语即时切换并记住选择；维吾尔语右到左布局、数字和文件名方向隔离，曲谱不镜像。
- 四语操作说明、状态、错误消息和导出提示。
- Windows 打包检查覆盖 PDF、PNG、TIFF、DOCX、AVIF、HEIC 和四种语言。
- 源码发布采用明确的公开文件清单，附隐私检查、素材摘要、可重复的 ZIP 文件元数据和 GitHub 上传指南。

旧版 `.doc` 需先在 Word 中另存为 `.docx`。Word 的文字或矢量水印不在此版本的清理范围内。多帧图片输出为静态页面，不保留动画时序。

解压整个 ZIP，双击 `ClearScore/净谱.exe`。保留 `_internal` 文件夹。

## v1.0.0

首个 Windows x64 桌面版本。

- 中文图形界面，支持拖放 PDF。
- 自动检测浅灰背景，保留深色像素并保护长水平谱线。
- 原始、清理后、左右对比和改动区域四种预览。
- 多页切换、缩放、平移、自动或手动强度。
- 原始图片分辨率、页面尺寸和页面绘制指令保持不变。
- PDF 无损压缩输出，原文件防覆盖，JSON 处理报告。
- 离线运行，无需账号或 API。

解压整个 ZIP，双击 `ClearScore/净谱.exe`。请保留 `_internal` 文件夹。

适合白底、深色谱面、浅灰背景的扫描 PDF。不能保证还原已与曲谱像素合并的水印；浅色谱面细节应通过预览核对。纯矢量水印、深色水印和复杂透明蒙版暂不支持自动清理。
